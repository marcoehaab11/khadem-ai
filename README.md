# خادم AI

مكتبة عربية لبرومبتات الذكاء الاصطناعي المساعدة في الخدمة المسيحية.

## المزايا

- بحث وتصنيف البرومبتات
- تعديل المتغيرات قبل النسخ
- نسخ سريع
- مفضلة محفوظة محليًا
- شرح ومثال استخدام لكل برومبت
- واجهة عربية RTL ومتجاوبة

المحتوى صياغات أصلية تعليمية مستوحاة من موضوعات منشورة علنًا لدى SparkTech، وليس نسخًا حرفيًا منها.
